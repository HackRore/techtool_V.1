# ⬡ HackRore TechWorkbench v1.0

**Professional Technician Platform — TestLab · ScanLab · FixLab**

By Ravindra Pandit Ahire | Hynet Technologies, Pune | HackRore@gmail.com

## Quick Start

```bash
npm install
npm run dev
# Open http://localhost:3000
```

## Modules

| Module | Description |
|--------|-------------|
| **TestLab** `/testlab` | 7 browser hardware tests: Keyboard, Screen, Webcam, Mic, Speaker, Mouse, Touchscreen |
| **ScanLab** `/scanlab` | Upload HackRore JSON report → full 17-module diagnostic dashboard |
| **FixLab** `/fixlab` | 50+ technician problems with causes, step-by-step solutions, tools |

## Deploy to Vercel

```bash
npx vercel
```

## Generate a ScanLab report

```powershell
# On Windows, run as Administrator:
.\HackRore_Master.ps1
# Upload Reports\HackRore_*.json to ScanLab
```
